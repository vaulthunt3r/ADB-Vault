# Security

Only the latest published version is maintained. This project does not promise
a fixed response time or enterprise support.

For a vulnerability, use **Security → Report a vulnerability** on the GitHub
repository when private reporting is enabled. Do not post exploit details,
credentials, private APKs, device backups or personal logs in a public issue.
If that option is unavailable, ask the maintainer to enable private reporting
without disclosing the vulnerability publicly.

ADB grants powerful access to an authorized device. Authorize only computers
you trust and turn off wireless debugging when it is no longer needed. APK
inspection is static; detection badges are heuristics, not a malware verdict.

Exports may contain private data and are not encrypted by ADB Vault. Check
archives, screenshots and logs before sharing them. Review
[privacy and network behavior](docs/PRIVACY.md) and
[known limitations](docs/USER-GUIDE.md#limitations).
