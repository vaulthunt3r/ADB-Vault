# ADB Vault 0.1.0 — first public preview

ADB Vault brings Android application management, two-panel file browsing,
screen/camera sessions and device diagnostics into a Windows desktop workspace.

## Highlights

- Seven workspaces: Components, Connection, Apps, Files, Monitor, Activity and Console.
- USB/Wi-Fi connections and explicit active-phone/profile selection.
- App search, package-list filtering, details, detection badges and personal notes.
- APK inspection, export and supported backup/restore operations.
- Phone screen, virtual app display and camera windows with always-on-top.
- PC-layout typing, optional touch mappings, editable presets and hotkeys.
- Themes, compact layouts, badge colors and optional Zero Cool effects.
- Skippable interface tour, replayable from the title bar.
- One Setup EXE offering Install or Portable, plus a standalone Portable ZIP.

## Downloads

Choose **Setup.exe** for the guided installation/extraction wizard, or extract
the entire **Portable.zip** into a writable folder. No system Java installation
is needed. Use Components on first launch to locate/download ADB/Fastboot and
optional scrcpy. Components may require separate upstream terms or privileges.

Required release assets:

- `ADB-Vault-0.1.0-Windows-x64-Setup.exe`
- `ADB-Vault-0.1.0-Windows-x64-Portable.zip`
- `ADB-Vault-0.1.0-Source.zip`
- `OpenJDK17U-jdk-sources_17.0.20.1_1.tar.gz` — matching complete source for bundled Java; not needed to run the app.
- `third-party-sources.json` — source provenance and upstream checksum.
- `SHA256SUMS.txt`

## Requirements and known limitations

Windows 10/11 x64; English interface. Device operations require an authorized
ADB connection. Local APK inspection works offline without a phone. The Android
helper targets API 26+, but firmware/device coverage is limited. Root, camera,
virtual display, input devices and provider access are subject to device support.

The preview is **not digitally signed**. Backup/export files are unencrypted.
Keep your own backups before changing packages or restoring data. Detection
classifications are heuristic, not malware verdicts. There is no dedicated
settings export/import function yet.

Close ADB Vault and its screen sessions before updating. Setup preserves the
existing profile; Portable users should retain `data/`. Read the user guide for
details and report reproducible issues with personal information removed.
