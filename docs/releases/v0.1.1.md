# ADB Vault 0.1.1 — Windows ADB setup

This public preview improves first launch for people who already have Android Platform Tools.

- ADB Vault checks the current Windows user and system `Path`, Android SDK locations, and explicit `ADB` or `ADB_PATH` settings. A working external ADB takes precedence over an older automatically downloaded copy.
- If ADB is missing, **Use existing ADB** appears in **Components** and **Connection**. Select `adb.exe`, select its folder, or paste the path. ADB Vault verifies the executable and remembers the choice.
- Google USB Driver detection can recognize a published driver when Windows denies the usual driver inventory query. The optional driver has its own install action. If USB already works, you can skip it.
- **Install / Repair All** appears only when a supported bulk action is available. Leaving the optional GeoIP database unconfigured does not prompt an installation.
- The Settings category bar stays visible while scrolling. Selecting another category opens it at the top.

**Windows 10/11 x64.** Download the Setup EXE for the installation wizard, or extract the Portable ZIP to a writable folder. Close ADB Vault before updating. When updating a portable copy, keep your existing `data` folder. Compare the download with `SHA256SUMS.txt`. The executables are unsigned.

The source ZIP, bundled Java's corresponding source archive and third-party source information are also attached. The preview has been tested on a limited set of devices. Please [report reproducible problems](https://github.com/vaulthunt3r/ADB-Vault/issues) with the Windows version, Android version and phone model. Remove personal data from reports.
