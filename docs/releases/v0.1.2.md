# ADB Vault 0.1.2 — Smaller Windows download

This release removes unused translation code and ships one English language pack for Electron. The unpacked language resources take up **50.6 MB less** than in 0.1.1. Both the installer and the portable edition include this change.

ADB Vault opens in English, including the camera and touch controls, even with a language preference from an early development build. Android app names, personal notes and text typed in a virtual display still support other languages.

**Windows 10/11 x64.** Choose the Setup EXE for guided installation or portable extraction, or download the Portable ZIP. Close ADB Vault before updating. For a portable update, extract into a new writable folder and move your existing `data` folder into it. The executables are unsigned. Checksums and corresponding source archives are included below.

Testing has covered a limited set of devices. Please [report reproducible problems](https://github.com/vaulthunt3r/ADB-Vault/issues) with your Windows version, Android version and phone model. Remove personal data from reports.
