# ADB Vault 0.1.3 — Screenshots and interface fixes

Phone screenshots can now be saved as PNG files and copied to the clipboard in one action. Choose either output or both in **Settings → Screen & audio → Screenshots**. The default folder is `Pictures\ADB Vault\Screenshots`; you can choose another folder or enable a Save As dialog for each capture. The clipboard contains an image for pasting into chats and image editors.

- Capture happens before the Save As dialog opens, so the screenshot preserves the moment you clicked. Automatic filenames avoid overwriting previous captures.
- Fixed scrolling past Settings into a blank area: the application frame now stays in place while its contents scroll.
- Sidebar icons stay in the same position when the sidebar is expanded or collapsed and align with its toggle.

These screenshot options apply to the phone screen. This release does not add screenshots of individual virtual displays.

**Windows 10/11 x64.** Choose the Setup EXE for guided installation or portable extraction, or download the Portable ZIP. Close ADB Vault before updating. For a portable update, extract into a new writable folder and move your existing `data` folder into it. The executables are unsigned. Checksums and corresponding source archives are included below.

**Public preview:** testing has covered a limited set of devices, Android versions and firmware. Bugs are possible. Please [report reproducible problems](https://github.com/vaulthunt3r/ADB-Vault/issues) with your Windows version, Android version and phone model. Remove personal data from reports.
