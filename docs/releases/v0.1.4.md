# ADB Vault 0.1.4 — Older Android compatibility and Removed apps

This update fixes application reading on older Android firmware and APK backups on phones without `sha256sum`. Removed apps now uses a compact table with selection and batch restoration.

- Fixed application collection on Android 8.1 firmware where the newer profile-context method is unavailable.
- Added application inventory support from Android 7.1 (API 25), with checks on a Redmi 4X. Owner and MIUI XSpace profiles remain separate. Fields that require newer Android APIs are reported as unavailable.
- Added verified helper transfer and APK checksum fallbacks for firmware without `sha256sum`. APK backups still verify file sizes and SHA-256 hashes, including split APKs. No companion APK installation is required.
- Replaced the Removed apps shortcut's refresh-like arrow with a package-minus icon.
- Changed Removed apps to a sortable table with compact personal notes, row checkboxes, filtered Select all and a selection count that includes hidden rows.
- Added Restore selected with one confirmation for the selected phone/profile, per-application results and skipped entries for unavailable APKs. The queue stops if the device changes or an operation's outcome cannot be verified.

Removed apps lists packages Android still knows about but does not have installed in the selected profile. It is **not a complete uninstall history** and can include preloaded packages never installed in that profile. Restoration uses APK files still on the phone; it does not recover deleted app data or reset disabled/frozen state.

**Validation:** application reading was checked on Redmi 5A (Android 8.1) and Redmi 4X (Android 7.1). The Android 7.1 check included owner/XSpace inventories and a real Google split-APK backup with both APKs verified. Batch restoration is covered by automated device/profile, cancellation, denial and connection-loss tests; it has not been exercised as a batch on those physical phones.

**Windows 10/11 x64.** Choose the Setup EXE for guided installation or portable extraction, or download the Portable ZIP. Close ADB Vault before updating. For a portable update, extract into a new writable folder and move your existing `data` folder into it. The executables are unsigned. Checksums and corresponding source archives are included.

**Public preview:** compatibility testing covers a limited set of devices and firmware. Android 7.1 inventory support does not mean every feature works on Android 7.1; some features require newer Android APIs. Please [report reproducible problems](https://github.com/vaulthunt3r/ADB-Vault/issues) with your Windows version, Android version and phone model, without personal data.
